# ⌨️ NvChad - Comandos Esenciales

## 📁 Comandos Generales
```bash
Space + ch                      # Abre el cheatsheet con todos los atajos
Space + th                      # Cambiar tema
:q                              # Salir
:w                              # Guardar
:wq                             # Guardar y salir
Ctrl + + + N                    # Abrir/cerrar explorador de archivos (NvimTree)
Space + + + E                   # Abrir explorador de archivos enfocado
Space + ff                      # Buscar archivos en todo el proyecto
Space + fb                      # Buscar entre archivos abiertos
Space + fw                      # Buscar palabra en el proyecto
Space + fo                      # Buscar archivos viejos
↑↓ o jk                         # Navegar arriba/abajo en NvimTree
Enter                           # Abrir archivo en NvimTree
m                               # Marcar archivo en NvimTree
a                               # Crear nuevo archivo en NvimTree
c                               # Copiar archivo en NvimTree
p                               # Pegar archivo en NvimTree
r                               # Renombrar archivo en NvimTree
d                               # Eliminar archivo en NvimTree
Ctrl + w + h/l                  # Cambiar entre árbol y editor
h                               # Mover izquierda
j                               # Mover abajo
k                               # Mover arriba
l                               # Mover derecha
0                               # Ir al inicio de la línea
_                               # Ir al primer carácter de la línea
$                               # Ir al final de la línea
gg                              # Ir al inicio del archivo
G                               # Ir al final del archivo
w                               # Saltar al inicio de la siguiente palabra
b                               # Saltar al inicio de la palabra anterior
e                               # Saltar al final de la siguiente palabra
f + [carácter]                  # Saltar al siguiente carácter en la línea
t + [carácter]                  # Saltar antes del siguiente carácter
;                               # Repetir búsqueda hacia adelante
,                               # Repetir búsqueda hacia atrás
i                               # Entrar en modo inserción
a                               # Insertar después del cursor
I                               # Insertar al inicio de la línea
A                               # Insertar al final de la línea
o                               # Nueva línea abajo
O                               # Nueva línea arriba
ESC                             # Volver a modo normal
yy                              # Copiar línea
dd                              # Cortar/eliminar línea
p                               # Pegar después
P                               # Pegar antes
d$                              # Eliminar hasta el final de la línea
y$                              # Copiar hasta el final de la línea
v                               # Modo visual (seleccionar caracteres)
V                               # Modo visual de línea
Ctrl + + + V                    # Modo visual de bloque
Tab                             # Cambiar al siguiente buffer
Shift + + + Tab                 # Cambiar al buffer anterior
Space + + + X                   # Cerrar buffer actual
:vsp                            # División vertical
:sp                             # División horizontal
Ctrl + + + H                    # Ir a ventana izquierda
Ctrl + + + J                    # Ir a ventana abajo
Ctrl + + + K                    # Ir a ventana arriba
Ctrl + + + L                    # Ir a ventana derecha
Space + + + H                   # Abrir terminal horizontal
Alt + + + H                     # Mostrar/ocultar terminal horizontal
Space + + + V                   # Abrir terminal vertical
Alt + + + V                     # Mostrar/ocultar terminal vertical
Space + + + N                   # Activar/desactivar números de línea
Space + rn                      # Activar/desactivar números relativos
gd                              # Ir a definición
gr                              # Ver referencias
K                               # Ver documentación
Space + ra                      # Renombrar símbolo
Space + ca                      # Code actions
gcc                             # Comentar/descomentar línea
gc                              # Comentar selección (en modo visual)
/ texto                         # Buscar hacia adelante
? texto                         # Buscar hacia atrás
n                               # Siguiente coincidencia
N                               # Anterior coincidencia
:%s/viejo/nuevo/g               # Reemplazar en todo el archivo
u                               # Deshacer
Ctrl + + + R                    # Rehacer
Ctrl + + + U                    # Subir media página
Ctrl + + + D                    # Bajar media página
Ctrl + + + B                    # Subir página completa
Ctrl + + + F                    # Bajar página completa
```

## ⚙️ Instalación y Configuración
```bash
:TSInstall [lenguaje]           # Instalar soporte de sintaxis
:TSInstallInfo                  # Ver lenguajes instalados
```

# ⚡ Warp - Comandos Esenciales

## 📁 Comandos Generales
```bash
D                               # Dividir panel a la derecha
Shift + + + D                   # Dividir panel hacia abajo
Alt + Flechas                   # Cambiar entre paneles
[                               # Activar panel anterior
]                               # Activar panel siguiente
Ctrl + Flechas                  # Redimensionar panel
Shift + + + Enter               # Maximizar panel
Ctrl + + + L                    # Abrir paleta de configuración
Ctrl + + + T                    # Abrir selector de tema
Ctrl + + + R                    # Buscar comando
Ctrl + + + Shift + + + R        # Flujos de trabajo
Ctrl + + + `                    # Sugerencias de comandos AI
L                               # Enfocar entrada de terminal
Ctrl + + + I                    # Warpify Subshell
C                               # Copiar
F                               # Buscar
V                               # Pegar
T                               # Abrir nueva pestaña
Shift + + + T                   # Reabrir pestaña cerrada
Ctrl + Shift + Izquierda        # Mover pestaña a la izquierda
Ctrl + Shift + Derecha          # Mover pestaña a la derecha
Shift + + + {                   # Activar pestaña anterior
Shift + + + }                   # Activar pestaña siguiente
1 + … + 8                       # Cambiar a pestaña 1‑8
9                               # Cambiar a la última pestaña
0                               # Tamaño de fuente por defecto
=                               # Aumentar tamaño de fuente
,                               # Abrir configuración
,                               # Configuración de cuenta
G                               # Buscar siguiente coincidencia
P                               # Paleta de comandos
R                               # Activar informes del ratón
K                               # Editor de atajos de teclado
Alt + Abajo                     # Seleccionar marcador más cercano hacia abajo
Alt + Arriba                    # Seleccionar marcador más cercano hacia arriba
A                               # Seleccionar todos los bloques
K                               # Limpiar bloques
B                               # Marcar bloque seleccionado
Abajo                           # Seleccionar siguiente bloque
Arriba                          # Seleccionar bloque anterior
Shift + + + C                   # Copiar salida del comando
Shift + + + I                   # Reingresar comandos con sudo
Shift + + + S                   # Compartir bloque seleccionado
M                               # Abrir menú contextual del bloque
I                               # Reingresar comandos
Shift + + + G                   # Buscar coincidencia anterior
Shift + + + P                   # Paleta de navegación
Ctrl + ` + texto                # Comando AI
Arriba / Abajo dentro de bloque  # Navegar entre bloques
P                               # Abrir paleta de comandos
Ctrl + + + T                    # Abrir selector de tema
Shift + + + Enter               # Alternar maximizar panel
```
